# Recorded audio for Dialogues: At School

Drop mp3 files directly in this folder (`/audio/dialogues-school/`)
using these exact filenames — `content/dialogues-school.js` already
points each turn at these paths, so nothing else needs to change once
the files are here.

**Every turn needs a recording — both "them" (Teacher) and "you"
(Student) lines.** The initial listen-through plays both sides of the
conversation, and the "you" line's recording is also what plays as the
answer reveal if a learner misses a turn twice.

## Behavior while files are missing

Same graceful fallback as everywhere else in the app: if a file 404s or
isn't there yet, playback transparently falls back to the browser's
text-to-speech for that one line instead of staying silent — so the
whole pack is testable (including the mic/scoring/retry logic) before
recording a single file, and real recordings can be added incrementally
afterward.
